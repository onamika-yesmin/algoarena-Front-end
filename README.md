# AlgoArena Frontend

Frontend repository structure for the AlgoArena application.

## Setup

```bash
npm install
npm run dev
```

## Environment variables

- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_SOCKET_URL`
- `NEXT_PUBLIC_APP_URL`

## Folder structure

- `app/` — application routes and global styles
- `components/` — UI component domains
- `hooks/` — future custom hooks
- `lib/` — API, socket, constants, and utility modules
- `providers/` — future application providers
- `types/` — shared TypeScript types
- `config/` — application configuration
- `public/` — static images, icons, and fonts
